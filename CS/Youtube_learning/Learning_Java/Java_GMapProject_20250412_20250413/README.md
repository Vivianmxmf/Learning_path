# Google Maps Project

This project is an Android application that integrates Google Maps to provide location-based services. Users can search for locations, get directions between two points, and view their current location on the map.

## Features

- Display Google Maps with various map types (Normal, Satellite, Terrain, Hybrid, None).
- Search for locations using a search bar.
- Get directions between two locations.
- View and interact with the map, including zoom and scroll gestures.
- Display the user's current location with a marker.

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/gmaps_project.git
   ```
2. **Open the project in Android Studio.**
3. **Build the project** to download dependencies and set up the environment.
4. **Run the application** on an Android device or emulator.

## Usage

- **Search for a location:** Enter a location in the search bar and submit to see it on the map.
- **Get directions:** Enter the starting and destination locations in the provided fields and click the "Get Directions" button.
- **Change map type:** Use the options menu to switch between different map types.

## Dependencies

- **Google Maps Android API**: For displaying and interacting with maps.
- **AndroidX Libraries**: For modern Android development practices.
- **Fused Location Provider**: For accessing the device's location.
